## 关键设计决定

1. **不做"测试模式 + 水印"的折中**：Duffel 测试模式的航班与价格来自沙盒航司 Duffel Airways
   （IATA `ZZ`），官方明说 "you won't see realistic flight schedules or prices"。允许它出现，
   用户就无法分辨哪行是真的，v1.14 的"价格未披露"语义也随之失效。故在 `status`/`availability()`
   层面直接拒绝，`search()` 连网络层都不触达（单测用假 opener 断言 `requests == []`）。
2. **外币不折算**：Duffel 请求侧无 `currency` 参数，同批结果可能混币种。汇率是会变的第三方
   数据，写死等于编价。非 CNY → 行保留、`price=None`、`price_note` 写外币金额与"不参与比价"。
3. **机场中文名放在适配器内**（`_AIRPORT_ZH_EXTRA`），**不进 `cities._CITIES`**：后者是 PRD
   定义的 50 城唯一事实来源，同时是网页下拉、CLI 校验与定价引擎的输入域，塞国际机场会改变
   可查航线范围。
4. **`tax_included=True`**：Duffel `total_amount` 官方口径含税费，引擎不再补机建/燃油。
5. **Amadeus 代码不删**：Enterprise 版仍是同族 OAuth2 + 同一套映射，将来若走合同可复用；
   渠道恒 `not_available` 并说明下线日期，比"静默消失"更诚实。

## 风险与缓解

| 风险 | 缓解 |
|---|---|
| 沙盒虚构数据被误当真价 | 硬闸门拒绝 test token；文档第 10 条固化 |
| 国际线大量外币行落到"未披露" | 行仍展示航班与外币金额；联调后按实际币种分布再评估展示策略（不引入折算） |
| Duffel 报价 20 分钟失效 | 缓存 15 分钟 + 行内标注有效期 |
| 机场/航司中文名不全 | 三级回退：本地表 → 上游名 → IATA 码，绝不猜译 |
| Duffel 调整 API 版本 | 版本号写死常量 `API_VERSION`，官方 v1 已停用说明会提前公告 |
