## 评审要点（自评审逐条过）

1. **价格不漏**：`available_flights()` 返回体经递归扫描，除 `price_returned` / `price_note` /
   `price_basis` 三个声明性键外无价格语义字段，且全文无 `¥`——由单测守住，不是靠自觉。
2. **不编造**：`flight_no` / `depart_time` / `arrive_time` 恒 `None` 且显式声明未披露；
   卡面未给的（有效期 / 卡费 / 税费口径）全部 NULL。
3. **不动既有比价链路**：`spring_store` 不进 `all_sources()`，不产出比价行，
   因此 `search_flights` / `/api/search` / `deals` 的输出结构与排序完全不变（全量回归佐证）。
4. **口径严谨**：跨税费口径不排名，改为分组 + 原因；这是本版唯一"故意不给结论"的地方。
5. **三入口同源**：Web 两个接口与 MCP 两个工具都直接调 `spring_store`，`webapp` 只做参数校验与翻译。
6. **零真实请求**：券库是本地 SQLite，无联网调用；测试**不设** `FARE_RADAR_OFFLINE`
   （避免 ISSUE-019 记载的进程级污染坑）。
