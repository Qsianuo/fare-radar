## 实现说明（对应分诊裁定）

- **规则唯一来源**：网页 API 只做"HTTP 参数 → JSON → 渲染"翻译；最低价准入、口径标注、退改不明/已售罄标记、"未披露"兜底、alerts 损坏拒写，全部复用 CLI 代码。用户在网页与命令行看到的结论保证一致（单测断言：SHA-CTU 含税 ¥459 券拿最低价、不含税行不得竞争）。
- **诚实披露**：页面顶部常驻"模拟数据 · 不能用于实际购票"徽标；团购卡五要素与 CLI 相同字段；低价提醒同样按"明天出发 + 准入规则"判断。
- **边界**：仅绑定 127.0.0.1；无用户系统、无真实数据、无部署；`alerts.json` 与 CLI 共享（同一份数据两个入口）。

## 风险与已知限制

1. watch 的 GET/POST 均接受查询参数，本地单用户工具可接受，不适合直接暴露公网（本就只绑回环）。
2. 网页无自动刷新/轮询，与 CLI 同为"查询时判断"。
3. 界面为原生实现，未做兼容性矩阵测试（Chrome/Edge 最新版实测通过）。
