# PR-027: Duffel 实测校准（响应级 live_mode 闸门 + 排序后截取）

- 分支: `feature/duffel-calibration` → `main`（`--no-ff`）
- 关联: ISSUE-026 / RELEASE-v1.16.1
- 日期: 2026-10-26
- 变更规模: 1 个适配器 + 1 份 fixture + 1 个测试模块 + 1 份文档

## 为什么是 patch 而不是 feature

v1.16.0 交付的适配器在结构上是完整的（闸门、缓存、限额、映射都在），但它的 fixture 是
"按官方文档构造"的样本，字段形态有几处假设未验证（时间是否带时区、航班号是整数还是字符串、
`aircraft` 是否可能为 null）。本轮用一次性 test token 打了三条真实航线，把假设逐条验证并
回填——**属于同一特性的实测收口**，不是新功能，故走 v1.16.1。

## 审查要点

1. **闸门是否会误伤 live 用户**：只有 `live_mode is False` 才拦；字段缺失（`None`）不拦，
   避免上游删字段导致全渠道哑掉。
2. **排序在混合币种下是否合理**：人民币优先是刻意的——只有 CNY 行能参与比价，让它们先占用
   12 个名额符合展示目的；外币行只作参考。
3. **是否引入新的联网路径**：没有。所有真实调用都在仓库外的一次性脚本里完成，测试仍全离线。
