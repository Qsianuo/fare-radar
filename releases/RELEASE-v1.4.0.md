# RELEASE v1.4.0 —— 航班 6 要素、多航司聚合、固定特价票与次卡、到手价口径

发布日期：2026-10-25 ｜ 关联：PR-011、ISSUE-011 ｜ 上一版本：v1.3.1
本轮 6 点需求全部来自产品评审人对照**真实春秋航空抖音小程序**的实测反馈。

## 🆕 六点交付

**① 航班信息完整化**：每个报价新增 起飞时间→到达时间（含 +1 跨日标注）、时长、起飞/降落机场全称、承运航司与航班号；每条航线早/午/晚至少各 1 班（确定性生成，300 航线对全量验证）。

**② 多航司聚合与去重**：6 家航司（国航 CA/东航 MU/南航 CZ/海航 HU/春秋 9C/吉祥 HO）按枢纽规则执飞；跨渠道去重（键=出发日期+航班号），保留到手最低价并标"另有 N 个渠道有售"；券/特价票/卡不参与去重。

**③ 固定特价票与次卡（对齐真实产品矩阵）**：
- **特价票**：21 条逐字采用真实小程序数据（上海→泉州 ¥179 10-27、上海→重庆 ¥189 10-27、上海→乌鲁木齐 ¥419 10-28、上海→和田 ¥1049 10-29 等），仅固定日期可售、固定航班时间，标注"不含机建燃油费/省¥41"；
- **次卡/省钱卡**：团购渠道按真实业务重构为卡类产品（199 秋冬单次卡、299 尊卡 MAX 版、79 省钱卡等 6 张卡面），以独立"卡提示"区块展示、不计入航班比价；"退改规则未披露"的诚实披露资产保留。

**④ 税费校验说明**：每个报价给出口径明细——"已含机建+燃油"或"另加机建 ¥50 + 燃油 ¥XX（票面 ¥N）"；到手价 = 票面 + 机建 + 燃油，成为排序、最低价、收藏命中的统一口径（正式修订 ISSUE-001 的"仅含税可比"裁定）。

**⑤ 春秋抖音小程序入口**：渠道链接更新为最新分享短链（v.douyin.com/USSyX47SP7s/，与此前链接指向同一春秋航空地点页）；外链接入评估结论：分享链接可跳转并引导拉起抖音 App，但无法直达小程序特定页面、token 会过期、无公开 Web API——接口级接入必须走抖音开放平台/商务合作（详见 docs/04 附录）。

**⑥ 纯国内城市全集**：移除全部国际城市，50 个国内城市（含机场全称，从北京首都到漠河古莲、和田昆冈）；存量收藏引用已下线城市的，显式标注"城市已下线"不静默删除。
