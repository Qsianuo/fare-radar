# RELEASE v1.2.0 —— 网页版上线

发布日期：2026-10-25 ｜ 关联：PR-007、ISSUE-007 ｜ 上一版本：v1.1.0

## 🆕 新功能：网页版（用户呼声第一名的改进）

"工具挺好用，但我得记命令……如果打开浏览器点点就能比价，会更直观。"——这是成果演示后收到的第一条功能建议，本版把它变成了现实。

**启动方式**：

```bash
python src/webapp.py        # 浏览器打开 http://127.0.0.1:8080
```

**你能在网页上做什么**（三个页签，与命令行能力一一对应）：

- 🔍 **搜索比价**：选出发/到达/日期，一键搜索。最低价行高亮并标"◀ 最低价"，团购价带"团购"徽标；不含税、售罄、有效期不覆盖的报价照样可见，但不会骗你出手。
- 🎫 **团购专区**：套餐卡片把价格、有效期、库存、退改规则、"需在抖音 App 内下单"全部摆在明面上，缺数据的显示"未披露"。
- 🔔 **低价提醒**：设一条航线的心理底价，每次比价自动帮你盯；"立即检查"按明天出发的模拟最低价逐条播报，命中即提示"可以出手了！"。

**最重要的一句话**：网页不是另一套逻辑——它和命令行共用同一套比价规则（同一批函数）。你在哪里查，结论都一样。
