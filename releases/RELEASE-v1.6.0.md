# RELEASE v1.6.0 —— 新增 Amadeus 真实接口渠道（默认关闭，自配 Key 激活）

发布日期：2026-10-25 ｜ 关联：PR-013、ISSUE-013 ｜ 上一版本：v1.5.0

## 🆕 新渠道：Amadeus 真实接口（可选启用）

应"如何使用真实数据"之问，工具内置了第一个**真实 API 数据源**——Amadeus Self-Service（国际 GDS 开发者平台，官方公开、免费注册）。

**默认关闭**：未配置 Key 时渠道显示"未配置 API Key"，不出数据、不假装接入。启用三步（详见 README）：

1. 到 https://developers.amadeus.com 注册并创建应用（免费）；
2. 复制 `src/sources/amadeus_config.example.json` 为 `amadeus_config.json` 填入 Key（可配代理）；
3. 重启服务，渠道即变为可用，结果行标注"真实接口·测试环境"。

**内置调用纪律**（对你的账号负责）：Token 缓存复用、同航线结果缓存 30 分钟、当日最多 200 次调用（到量自动停当日渠道）、超时 10 秒、遇 429 立即停不重试。

## 📌 诚实披露

- Amadeus 对中国国内航线覆盖有限：返回为空时如实显示"无报价"，不编造；价格为其含税总价口径，不拆分机建/燃油。
- 当前网络环境下需确保代理放行 `*.amadeus.com`（本机代理为规则模式时默认不放行）。
- 国内航线的完整真实数据仍以"实测快照"为准（欢迎继续供截图扩充）。
