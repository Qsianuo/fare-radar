## 顺带修掉一个会花钱的 P0

`CONFIG_NAME` 离线补丁只对**当前进程**生效。MCP 的 stdio 集成测试用 `subprocess`
拉起真实服务，补丁失效 → **用真实 Key 发起了一次付费调用**（实测产生 4 条真实数据）。

修复：新增 `FARE_RADAR_OFFLINE=1` 全局离线开关，三个联网适配器全部短路；子进程测试显式传参。
验证方式改为「跑完全量测试后检查缓存目录是否存在」——现在不存在。

## 质量

- **191 例全绿**（+15 例），全程零真实请求
- 三入口一致：CLI / Web `/api/search` / MCP `search_flights` 输出同一批行与同一口径
- 积分护栏：按最坏单价 50 预扣，日 500（¥5）/ 月 4500（¥45）硬停，不自动充值

## 已知限制

1. 上游 `oilfee`/`tax` 为空，**票价是否含税未明示**，到手价含估算成分（界面已标"以下单页为准"）。
2. 承运人中文名为本地补充表，未收录航司只显示航班号（不拿二字码冒充中文名）。
3. 每次查询约 ¥0.05–0.5，额度有限；日常演示建议用已缓存航线。
4. 上游舱位数据存在不一致（同 booking code 不同舱位名），已按 `cabinclass` 规则退化处理。
