## 这版解决了什么（一句话）

以前只能看"你选的那一天"多少钱，现在能看 **这个月哪天飞最便宜**——免费、不花配额、不参与比价。

## 新增：整月最低参考价

搜索后仪表区新增一块「整月最便宜（参考价，非可售）」：

```
2026-11-30  ¥1235  HU7609
2026-11-28  ¥1260  HU7609
2026-11-01  ¥1267  MU5100
2026-11-23  ¥1297  MU5162
2026-11-10  ¥1300  MU5128
```

数据来自 Aviasales（Travelpayouts 联盟，**免费**），缓存 12 小时。CLI 同样输出一行：
`整月最便宜（参考价·非可售，来源：Aviasales·价格日历）：11-30 ¥1235｜…`

## 它不做什么（重要）

- **不写进比价列表**、不参与到手价排序、不触发你的底价提醒
- 只有「日期 + 最低价 + 航司 + 航班号」，**没有起降时刻、机场、舱位、机型**
- 是**参考价**（搜索缓存），不是可售报价——界面与接口都标注了这一点

## 覆盖情况（实测，务必知情）

| 航线 | 2026-11 有价天数 |
|---|---|
| HRB→SYX | 143 |
| SHA→CTU | 36 |
| CAN→CTU | 16 |
| INC→PEK | 4 |
| INC→CTU | 2 |
| INC→CAN / XMN→PEK / LHW→SZX / WNZ→CAN / KMG→HGH | 0 |

**上游只收录"被搜索过"的航线**，所以覆盖不可预期。设计上采用「有则显示、无则显示暂无」，
不补、不推、不猜。

## 顺带修的契约

新增 `offer_channel` 标记：不产出比价行的渠道（如价格日历）仍会被引擎登记说明，
但**不会**被展示成"本次无销售"——避免把"不参与比价"误报成"卖不了"。

## 质量

- **198 例全绿**（+7 例），全程零真实请求
- 端到端三情形通过：有数据（PEK→SHA 5 天）/ 无覆盖（INC→CAN 0 天，提示明确）/ 非法 month（400）
- 费用：**免费**（联盟 token，无按次计费）

## 已知限制

1. 覆盖不稳定，小机场（如银川）常常没有。
2. 无时刻/舱位，不能替代飞常准或快照做决策。
3. 上游日期窗口是滚动半年，本版已按请求月份裁剪。
