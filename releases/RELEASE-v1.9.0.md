## 这版解决了什么（一句话）

**从"只有一条航线有真实数据"变成"任意 50 城航线按需查真实报价"**——v1.5 的快照层解决了"零编造"，但覆盖面只有 INC→CAN 一条；本版接入 Google Flights 后，任意航线的真实报价都能按需取到。

## 新数据源

- **上游**：RapidAPI「Google Flights Search & Prices」免费档（独立 100 次/月，无需信用卡）。
- **能力**：**IATA 三字码直查任意航线**（SHA / CAN / CTU …），不再依赖城市名→三字码映射，消除映射开销与错配风险。
- **被替换**：v1.7 的 Flights Scraper Sky（Skyscanner 抓取）因上游持续故障（502 / 反爬拦截）不可依赖，退场（历史见 git）。
- **映射字段**：合并 best/other 行程前 8 条；航班号（含中转拼接）/ 起降时刻 / 跨日 / 时长 / 机场英文全称（上游权威名）/ 机型 / 舱位 / 含税价全量映射；**无价格行程直接丢弃**。

## 调用纪律（内置，非口头约定）

| 项 | v1.7 | v1.9.0 |
|---|---|---|
| 结果缓存 | 30 分钟 | **6 小时**（价格日级波动，显著放大有效查询量） |
| 日限 | 60 次 | **40 次** |
| 月限 | 无 | **90 次**（100/月 保护线） |
| 超时 | 15 秒 | **45 秒** |

- **WAF 403 修复**：RapidAPI 前置 WAF 会拦截 urllib 默认 UA，适配器改为携带可溯源自定义 User-Agent——**后续改动请求头时不得删除**（HANDOFF §6 第 2 条）。

## 已知限制

1. **配额天花板**：免费档 100 次/月（自设月限 90、日限 40），高频需求需付费档（约 $10/月）或用实测快照补充（零配额消耗）。
2. **`price_insights` 未入结果**：API 已返回低价洞察（最低价 / 常规区间 / 60 天价格历史），尚未映射进比价行与仪表——已记为下一步最高价值项（缓存结构变更需同步改离线测试）。
3. 报价为上游**含税总价**，不拆机建/燃油，与"到手价统一可比"口径的展示层对齐仍需标注。
4. 上游为第三方聚合报价，**最终以航司/OTA 下单页为准**。
