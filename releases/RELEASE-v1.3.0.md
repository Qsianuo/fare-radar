# RELEASE v1.3.0 —— 网页版体验升级：城市全集、五票源、价格仪表、收藏航线

发布日期：2026-10-25 ｜ 关联：PR-009、ISSUE-009 ｜ 上一版本：v1.2.1

本轮全部需求来自产品评审人对网页版的 7 点实测反馈——这是一次完全由用户视角驱动的迭代。

## 🆕 新功能与改进

**① 城市全集 + 全中文化**
出发/到达改为 25 个城市的完整中文下拉（北上广深、成都、杭州、西安、三亚、哈尔滨……以及香港、大阪、曼谷、东京、首尔），新增"交换"按钮。任何两个城市之间都能查询——票价按距离确定性生成，偏远航线同样有报价。

**② 票源家族从 2 个扩到 5 个，命名全部说人话**
- 航司直连：官网/小程序直飞正班
- OTA 比价：多平台聚合，可能有更低价，但退改更严、可能收服务费
- 抖音团购：精选套餐券（春秋航空等）
- 抖音小程序·春秋航空：航司自营抖音小程序特价，不含行李额
- 抖音直播间：直播间闪购，低价但库存少、有效期短
结果表里不再出现"模拟"字样；"演示数据"声明常驻页头，绝不消失。

**③ 首页大号价格仪表**
打开页面即看到：当前最低价大字展示 + 今日区间弧形表盘 + 近 24 小时价格走势曲线 + 自动刷新开关（30/60 秒）。价格按分钟确定性小幅起伏（标注"演示波动"——同一分钟你在网页和命令行查到的价永远一致）。

**④ 收藏航线（替代"低价提醒"）**
把常查的航线收藏起来，底价选填；收藏页一眼看到每条航线的当前最低价，低于底价的显示绿色徽章，支持一键去查价、删除。与命令行 watch 数据同源。

**⑤ UI 全面重做**
设计令牌系统（色板/间距/圆角/三级阴影）、渐变主视觉、卡片化层级、粘性表头、骨架屏加载、微交互动画、三档响应式。图标全部内联 SVG，依旧零外部依赖。

## 🔧 质量

- 单测从 39 例扩至 60 例：新增任意偏远航线、分钟波动跨入口一致性、trend/cities 契约、5 源合并与准入规则。
- 诚实披露红线与"规则唯一来源"红线全部保留并通过测试锁定。

## 📌 说明

- 数据仍为内置演示数据：价格曲线是确定性生成的重放，不是真实行情，页面有明确标注。
- 命令行用法保持兼容，新票源自动进入 CLI 比价与团购专区。
