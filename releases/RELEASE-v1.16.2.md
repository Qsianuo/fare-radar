# RELEASE v1.16.2 · Duffel 激活路径判定关闭（文案改真，无功能变更）

**发布日期**：2026-10-27

## 一句话

走完整套 Stripe KYC 后确认：Duffel 的 live 激活要求美国身份（美国地址 + 州 + `+1` 电话 +
SSN 后四位，国家下拉锁死「美国」），中国大陆个人无合法路径。渠道保持 `not_available`，
文案改为如实说明，并加测试防止被改回误导版本。

## 变更内容

### 修正
- `duffel` 渠道的拒绝原因、`tagline`、`entry_note` 全部改为「需 Stripe KYC + 美国身份，
  大陆个人不可用」，不再出现「注册后自配 Key 启用」的旧说法。
- README、`docs/10` 同步落文（含 KYC 逐项实测表与三条可行路径）。

### 测试
- `tests/test_duffel.py` +2 例，锁住文案必含 `Stripe / 美国 / SSN / 中国大陆`；
  全量 291 例通过，零真实请求（juhe 计数器跑前跑后一致，未生成 `.duffel_cache/`）。

### 未变更
- 适配器逻辑、闸门（token 前缀 + `live_mode`）、缓存与日限、排序后截取——一律未动。
- 未创建任何 live token，未改动 Duffel 账号（探测令牌已全部删除）。

## 两条硬结论（供后续决策直接引用）

1. **Duffel 对大陆个人不可用**，不是填表技巧问题；想走通需美国/香港/新加坡主体。
2. **就算激活也不解决比价问题**：实测三条航线（PVG→LHR / PVG→PEK / CAN→CTU）报价
   **全为 USD**，按「外币不折算」红线不参与比价，撑不起「低于底价」判定。
