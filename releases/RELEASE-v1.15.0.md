# RELEASE v1.15.0 —— 国内线终于有价了：接入聚合数据

| 项 | 内容 |
|---|---|
| 发布日期 | 2026-10-26 |
| 关联 | **ISSUE-024**｜PR-025 |
| 升级建议 | 建议升级。新增一个能出价的国内源；不改任何既有接口字段（纯增量） |

## 一句话

在 RapidAPI 之外接了一个**真能出价**的国内源：同一条奥凯 BK3037（银川→深圳），
Google Flights 返回 `price: null`，聚合数据给 **¥918**。

## 新增渠道：聚合数据·航班机票（`juhe_flight`）

| 项 | 说明 |
|---|---|
| 覆盖 | 国内航线为主，含中转联程（1 次中转常见） |
| 有价率 | 实测 `INC→SZX 2026-10-28`：**33 条全部带价**（¥918–¥3160） |
| 时效 | 缓存票价，非秒级实时（`note` 逐行标注） |
| 计费 | 按次；试用仅 3 次，正价 ¥99/450 次 ≈ 0.22 元/次 |
| 护栏 | **当日 20 次 / 当月 60 次硬停**，触顶降级并给中文原因，绝不自动充值 |
| 缓存 | 结果 6 小时，空结果 30 分钟 |

## 你会看到的变化

- `/api/sources` 与 CLI 渠道清单多一项「聚合数据·航班机票」；未配 Key 时为
  `not_available` 且**不发任何请求**；
- 国内航线的比价行变多、带价率变高，价格标注"票面价，是否含税上游未明示"，
  到手价按"机建 ¥50 + 燃油"补全并逐行展示明细；
- 中转航班如实写成「2 段联程（中转城市未披露）」——上游不给中转城市，就**不编**"经 XX 中转"；
- 承运人中文名以本地表为准：不会再看到「Okay航空公司」「中国快运航空公司」这类机翻。

## 修复

- **测试离线注入失效**（红线第 5 次复发）：`unittest discover` 下 `tests/__init__.py` 不执行，
  导致新源在测试里真实联网、消耗按次计费额度。已补 5 个模块注入 + 新增
  `tests/test_offline_guard.py` 守卫，任何"忘注入"会直接指名报错。

## 未采纳

产品文档中"所有源无价时启用本地 **Mock 票价**"的降级策略**未采纳**——与「零编造」红线冲突，
会把 v1.14.0 的"价格未披露"语义抹平。如确需演示能力，须 `--demo` 显式开关 + 全链路水印 +
不参与排序与提醒，且需明确授权后才做。

## 验证

- 全量 **264 例全绿**（240 + 21 + 3），测试期间**零真实请求**（计数器前后一致）；
- 引擎集成实测：`INC→CAN 2026-11-01` 去重后 29 条，税费与到手价全部由引擎补全。

## 已知限制

- 聚合数据试用额度已耗尽，真实联调需购买 ¥99/450 次档（无需改代码，重启即可）；
- 无舱位类型、无余票、无机建燃油拆分（`segments` 实测恒为空）；
- 跨天联程可能价低但耗时长，排序只看价格，由用户自行权衡。
