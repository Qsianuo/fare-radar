# RELEASE v1.3.1 —— 诚实性补丁：真实渠道没有的航班，不再编价

发布日期：2026-10-25 ｜ 关联：PR-010、ISSUE-010（诚实性 P0）｜ 上一版本：v1.3.0

## 🐛 修复了什么（一个真实的用户发现）

产品评审人用**真实的春秋航空抖音小程序**查"郑州→西安 10/26"，真实结果是"暂无可销售座位"（春秋不执飞该航线）；而本工具却给出"¥318 春秋特价直飞"。演示数据编造了真实世界不存在的航班——这比"没有数据"更糟，用户会拿着它做错误的出行决策。

**修复**：每个渠道现在有了"覆盖范围"——

- 航司直连 / OTA 比价：覆盖全部 25 城；
- **抖音小程序·春秋航空：只飞春秋基地航线**（上海/沈阳/深圳/大阪至少一端），且偶尔模拟"当日无座"（约 1/7 的日期，还原真实的"暂无可销售座位"体验）；
- 抖音团购：只上精选套餐航线；抖音直播间：场次按天轮换。

搜索时，**没货的渠道不再悄悄消失**：页面与命令行都会明确列出"渠道「X」本次无销售：原因"。郑州→西安现在只会给出航司直连与 OTA 的真实合理报价，春秋小程序渠道显示"该航线可能未执飞"。
