# ISSUE-006: 最便宜的券退改"未披露"，卡面上还印着"模拟源数据不完整：退改规则字段缺失"这种我看不懂的话

- 提交人: User A | 日期: 2026-10-24 | 状态: 已确认（Bug/P2，v1.1.0 修复）
- 类型: 💡体验

## 问题描述（我在做什么时遇到了什么，用户视角）

我按 README 查成都的团购专区，最便宜的 ¥459 川航双城券，退改规则一栏写着"未披露，下单前请在购买页确认"，下面限制条件还跟着一行"**模拟源数据不完整：退改规则字段缺失**"。这后半句我完全看不懂，像是程序内部出错的话直接印在我脸上。更让我难受的是：同事在直播间买券翻车，翻的都是退改——不能退、过期作废这些坑。团购券最大的坑恰恰就是退改规则，结果最便宜的那张看不到退改，只让我"去购买页确认"。我要是能信购买页写得清楚，我就不需要这个工具了。

## 复现步骤

1. 运行 `python src/fareradar.py deals --from SHA --to CTU`。
2. 查看套餐 [DY-005]（川航联营 上海-成都 双城券）的"退改规则"与"限制条件"两行。
3. （可由总协调者补充：确认该文案出自数据源缺字段时的兜底分支，检查是否有其他套餐会走到同样文案。）

## 预期结果

- 不要把"字段缺失"这类程序术语显示给用户。
- 用我听得懂的话提示风险，比如："商家没有公布退改规则，这种券风险最高；下单前务必在抖音购买页核对退改条款，并截图留证。"
- 在 `search` 结果里，这种退改不明的券最好加个"退改不明"标记，别只标"◀ 最低价"。

## 实际结果

卡面原文为：

```
│ 退改规则：未披露，下单前请在购买页确认
│ 限制条件：模拟源数据不完整：退改规则字段缺失
```

"未披露"我能懂，但"模拟源数据不完整：退改规则字段缺失"是开发者视角的话，普通用户无法理解，也不像是有意的产品设计。

## 对用户的影响

一行看不懂的话让我怀疑这工具是不是出 bug 了；而它没把"最便宜的券退改不明"这个真正要命的坑翻译成我能懂、能行动的提醒，恰恰在最需要把关的地方缺了位。
