# ISSUE-011: 机票查询 v1.4.0 迭代——时间/机场字段、多航司聚合去重、固定特价票、税费说明、渠道入口更新、国内城市全集

- 提交人: 产品评审人（对照真实春秋航空抖音小程序实测） | 日期: 2025-10-26 → 实际 2026-10-25 | 状态: 已确认（功能迭代批次，v1.4.0 实现）
- 类型: ✨新功能 / 💡体验 / ⚙️业务逻辑核对（混合批次，逐点处置见 Triage）

## 评审人原话与证据（6 点）

1. 【时间与地点字段】查询结果只显示日期（如 11月25日），需补全每个航班的**起飞时间、到达时间、起飞机场、降落机场**，并确保结果**覆盖全天所有时间段（早、中、晚各时段）**。
2. 【多航司聚合】当前仅调用春秋航空接口，需**接入多家航司接口**并对结果进行**聚合、去重、统一排序**展示。
3. 【固定特价票核对】小程序中**团购机票的航班与航线均为固定值**（评审人提供真实截图：上海→泉州 ¥179 10-27、上海→重庆 ¥189 10-27、上海→沈阳 ¥189 10-29、上海→广州 ¥219 10-27、上海→张家口 ¥219 11-04、上海→深圳 ¥229 11-04、上海→遵义 ¥229 11-02、上海→西安 ¥249 11-21、上海→昆明 ¥259 10-29、上海→贵阳 ¥309 11-04、上海→常德 ¥329 10-27、上海→黔江(重庆) ¥339 10-27、上海→西双版纳 ¥349 10-27、上海→丽江 ¥359 10-26、上海→绵阳 ¥369 11-07、上海→大理 ¥389 11-16、上海→乌鲁木齐 ¥419 10-28、上海→阿勒泰 ¥429 11-06、上海→漠河 ¥569 10-29、上海→三亚 ¥609 10-28、上海→和田 ¥1049 10-29，标注"省¥41""不含机建燃油费"），请据此**核对相关展示与业务逻辑，确保二者一致**（固定航线+固定日期+固定价格，仅在对应日期可售）。
4. 【税费校验】在总价格位置增加校验：**明确标示是否已计入机建费与航油费**，配清晰文字说明（真实小程序即区分"不含机建燃油费"与"含税费等"两种口径）。
5. 【春秋抖音小程序特殊渠道入口】用户点"特价票"图标后进入固定航线机票列表（评审人提供流程截图与新分享链接 https://www.iesdouyin.com/share/microapp/?token=RTYwNDUxQzcyRjJDNzZqc2I4NWtt&share_channel=copy ）；**评估并说明是否存在外置链接的接入方式**。→ 总协调者评估结论：分享链接可作为外链入口跳转（引导拉起抖音 App），但无法直达小程序内特定页面、token 会过期轮换、无公开 Web API；接口级接入必须走抖音开放平台/商务合作，不在演示工具范围。本轮更新为该新链接并在调研文档沉淀结论。
6. 【国内城市全集】第一版必须**完整覆盖国内航班查询，全部移除国外城市选项**（香港/大阪/曼谷/东京/首尔等全部移除；真实特价票中的国际线路不纳入城市范围，仅国内线路进特价票清单）。

## 对用户的影响

当前版本"有价无航班、单航司、税费含糊"，与真实购票决策所需信息（几点飞、从哪个机场、到手多少钱、哪家航司）差距大。本批次让工具的信息结构对齐真实机票产品。

## 红线约束（总协调者补记）

- 演示数据声明与"不编造"红线继续有效：固定特价票必须只在其固定日期可售；多航司航班按确定性生成（无随机）；渠道覆盖模型保留。
- 规则唯一来源：CLI 与网页继续共用同一批函数；纯标准库。
- 口径演进：机建/燃油费用确定化后，最低价竞争口径由"仅含税价可比"升级为"**到手价（票面+机建+燃油）统一可比**"——此为对 ISSUE-001 裁定的修订，需 PM 在 PRD v1.4 正式裁定并同步全部测试。
