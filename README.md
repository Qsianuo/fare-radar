# 低价票雷达 FareRadar

**这是什么**：一个"不装"的机票比价演示工具——把 **5 个票源**（航司直连 / OTA 比价 / 抖音团购 / 抖音小程序·春秋航空 / 抖音直播间）放进同一个窗口，**25 城**任意航线一查便知，最低价一目了然，团购券的坑（有效期、退改、去哪下单）写在明面上。有命令行和本机网页两种用法，两者共用同一套规则：同一分钟查同一条航线，两边价格一致。

**这不是什么**：它不卖票、不收钱、不接真实行情——所有价格都是**演示数据**，且带**分钟级演示波动**（价格会小幅起伏，但这是确定性生成的，不是真实市场）。

**怎么用**：只需要 Python 3.10+，零安装、零配置。推荐网页版（浏览器点点就能用），也保留完整命令行（`search` / `deals` / `watch`）。

## 环境要求

- Windows 10/11 + Git Bash（或任何能跑 Python 的终端）；可选浏览器看网页版
- Python 3.10+，**只依赖标准库，无需 pip 安装任何东西**

## 3 分钟上手

```bash
cd fare-radar

# 命令行：搜索比价（出发三字码 --from、到达三字码 --to、日期 --date）
python src/fareradar.py search --from SHA --to CTU --date 2026-11-15

# 网页版：本机启动后浏览器打开 http://127.0.0.1:8080（--port 可换端口）
python src/webapp.py
```

## 命令参考

| 命令 | 作用 | 说明 |
|---|---|---|
| `search --from A --to B --date D` | 5 票源比价：可比价升序 + `◀ 最低价` 标记 | `--source airline/ota/douyin_groupbuy/douyin_miniapp/douyin_live` 只查一个票源 |
| `deals [--from A] [--to B]` | 团购专区：抖音团购精选券 + 直播间闪购卡 | 卡面含价格/有效期/库存/退改规则/下单提示 |
| `watch --from A --to B [--price N]` | 收藏航线，底价可省略 | 存于仓库根 `alerts.json`，与网页"收藏航线"同源 |
| `watch` / `watch --list` / `watch --from A --to B --remove` | 检查 / 列表 / 删除收藏 | 底价为空的收藏只看当前最低价，不触发提醒 |

最低价准入：不含税（税费另计）、已售罄、券有效期不覆盖出发日期的报价都**不参与**"◀ 最低价"竞争与提醒，只在行内标注原因。城市码不在 25 城清单会得到中文提示，不会编造。

## 常见问题

**数据是演示的吗？** 是。每一屏输出首行都有"[演示数据]"声明；价格由确定性引擎生成（按城市距离 + 票源特征 + 星期），不接真实行情，也不能购票。

**价格为什么会变？** 那是"**演示波动**"：分钟级确定性小幅起伏（±3.5% 以内，无随机数）。同一分钟内任何入口（CLI/网页）查同航线价格完全一致，隔几分钟再看会不同——这是让你感受"价格在动"的练习场设定，不是真实行情。

**团购票怎么买？** 本工具不能购买。卡面"下单方式"写明去哪买（抖音 App / 小程序 / 直播间）；退改规则显示"未披露"的券风险最高，下单前务必在购买页核对并截图留证。

**为什么比官网便宜？** 演示数据还原的是现实中抖音系渠道的定价逻辑：补贴与闪购带来低价，代价是有效期短、限指定航班、退改苛刻甚至不可退。便宜和限制是同一枚硬币的两面，工具把它们一起给你看。

**为什么有的渠道搜不到？** 每个渠道有覆盖范围：抖音小程序·春秋航空仅飞春秋基地航线（上海/沈阳/深圳/大阪至少一端），且约每 7 天有一天确定性模拟"当日无座"（还原真实渠道"暂无可销售座位"）；抖音团购仅精选套餐航线；抖音直播间场次每日轮换。渠道本次无销售时，CLI 会列出"以下渠道本次无销售：XX（原因）"、网页返回 `unavailable_sources`——**宁可没有报价，也不编造真实世界不存在的航班**。报价行和团购卡带渠道入口链接，可去真实渠道自行核实。

## 已知限制（v1.3.0）

- 全部数据为内置演示数据；不含税票价不做税费估算，仅作"税费另计"披露。
- 不出票、不支付、不跳转；收藏无后台轮询（每次运行时检查一次）。
- 价格为分钟级演示波动，同一分钟内一致；不是实时行情，也不预测未来价格。
- 暂不支持往返、多航段、舱位/时段筛选与 `--json` 机读输出。
