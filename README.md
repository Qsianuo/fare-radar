# 低价票雷达 FareRadar

**这是什么**：一个"不装"的机票比价演示工具——把 **5 个票源**（航司直连 / OTA 比价 / 抖音团购 / 抖音小程序·春秋航空 / 抖音直播间）放进同一个窗口，**50 个国内城市**任意航线一查便知：几点飞、从哪个机场到哪个机场、哪家航司执飞、到手多少钱（机建燃油一目了然）。跨渠道同一航班自动去重并标注"另有 N 个渠道有售"；21 条固定特价票跟真实截图一个样；团购渠道按真实产品形态卖"卡"而不是航班票。有命令行和本机网页两种用法，两者共用同一套规则：同一分钟查同一条航线，两边价格一致。

**这不是什么**：它不卖票、不收钱、不接真实行情——所有价格都是**演示数据**，且带**分钟级演示波动**（价格会小幅起伏，但这是确定性生成的，不是真实市场）。

**怎么用**：只需要 Python 3.10+，零安装、零配置。推荐网页版（浏览器点点就能用），也保留完整命令行（`search` / `deals` / `watch`）。

## 环境要求

- Windows 10/11 + Git Bash（或任何能跑 Python 的终端）；可选浏览器看网页版
- Python 3.10+，**只依赖标准库，无需 pip 安装任何东西**


## 命令参考

| 命令 | 作用 | 说明 |
|---|---|---|
| `search --from A --to B --date D` | 全票源比价：到手价升序 + `◀ 最低价` 标记，含时间/机场/航司/航班号/税费明细 | `--source airline/ota/douyin_groupbuy/douyin_miniapp/douyin_live` 只查一个票源 |
| `deals [--from A] [--to B]` | 特价票清单（21 条固定特价票）+ 卡池卡面（价格/有效期/退改/下单提示） | 固定特价票仅其固定日期可售 |
| `watch --from A --to B [--price N]` | 收藏航线，底价可省略；按**到手价**判断命中 | 存于仓库根 `alerts.json`，与网页"收藏航线"同源 |
| `watch` / `watch --list` / `watch --from A --to B --remove` | 检查 / 列表 / 删除收藏 | 底价为空的收藏只看当前最低到手价；引用已下线城市的收藏显式标注"城市已下线"且不触发查询 |

最低价准入：已售罄、券有效期不覆盖出发日期的报价**不参与**"◀ 最低价"竞争与提醒，只在行内标注原因。v1.4 起费用确定化，含税/不含税行统一按到手价可比（"税费另计退出竞争"的旧口径退役）。城市码不在 50 城清单会得到中文提示（已下线的国际城市会显式标"城市已下线"），不会编造。

## 常见问题

**数据是演示的吗？** 是。每一屏输出首行都有"[演示数据]"声明；价格由确定性引擎生成（按城市距离 + 票源特征 + 星期），不接真实行情，也不能购票。

**到手价怎么算？** 到手价 = 票面价 + 机建 ¥50/人 + 燃油附加费（航线大圆距离 ≤800km ¥20/人、>800km ¥40/人）。票面"已含机建+燃油"的报到手价=票面价；特价票沿用真实截图的"不含机建燃油费"标签，到手价同样加税费后展示与比价。排序、最低价标记、收藏提醒全部按到手价（v1.4 正式修订，取代旧"仅含税可比"口径）。

**价格为什么会变？** 那是"**演示波动**"：分钟级确定性小幅起伏（±3.5% 以内，无随机数）。同一分钟内任何入口（CLI/网页）查同航线价格完全一致，隔几分钟再看会不同——这是让你感受"价格在动"的练习场设定，不是真实行情。

**为什么同一航班只出现一次？** 去重键=出发日期+航班号：OTA 代理票与航司直连卖同一物理航班时合并为一行，保留到手最低价并标"另有 N 个渠道有售"；同渠道早/午/晚多班次（不同航班号）不去重；券、卡与固定特价票不参与去重。

**21 条特价票是怎么回事？** 逐字复刻真实小程序的固定特价票（如 10-27 上海→泉州 ¥179、10-29 上海→漠河 ¥569，全部标"省 ¥41""不含机建燃油费"）：固定航线+固定日期+固定价+固定航班时间，**仅当日可售**，其余日期该航线走春秋会员价常规航班逻辑。用 `deals` 可一次看全 21 条。

**抖音团购为什么不出现在比价行里？** 真实团购卖的是**卡**（固定有效期+固定价+适用航线集合），不是某天的具体航班：命中适用航线时结果顶部给"卡提示"块（`card_hints`），`deals` 列出全部卡面。四张卡真实截图未展示退改条款，显著标"**退改规则未披露**"；一张秋季单次卡确定性售罄——坑写在明面上，买不买你自己定。

**团购/小程序的入口链接是什么？** 两者统一为评审人最新提供的春秋航空抖音地点页短链 `https://v.douyin.com/USSyX47SP7s/`，点击可拉起抖音 App；但**无法直达小程序内特定页面、token 会过期、无公开 Web API**——接口级接入需官方合作，不在演示工具范围（评估结论见 docs/04 附录）。

**为什么有的渠道搜不到？** 每个渠道有覆盖范围：抖音小程序·春秋航空仅飞春秋基地航线（上海/沈阳/深圳至少一端）∪ 21 条特价票航线，且约每 7 天有一天确定性模拟"当日无座"；抖音团购为卡类渠道不卖航班票；抖音直播间场次每日轮换。渠道本次无销售时，CLI 会列出"以下渠道本次无销售：XX（原因）"、网页返回 `unavailable_sources`——**宁可没有报价，也不编造真实世界不存在的航班**。

**v1.3 之前收藏的国际城市（如香港）还能用吗？** 能看到，不能再用：收藏列表会显式标注"城市已下线（v1.4 城市全集收缩）"，不参与比价与提醒，也不会被静默删除；确认不需要后可自行删除。

## 已知限制（v1.4.0）

- 全部数据为内置演示数据；税费为确定化演示口径（机建 50 + 距离分档燃油），非真实征收标准。
- 不出票、不支付、不跳转；收藏无后台轮询（每次运行时检查一次）。
- 价格为分钟级演示波动，同一分钟内一致；不是实时行情，也不预测未来价格。
- 同城多机场（如虹桥/浦东）按注册表唯一机场演示；暂不支持往返、多航段、舱位/时段筛选与 `--json` 机读输出。

## 接入 Amadeus 真实接口（可选，默认关闭）

工具内置一个**真实 API 票源**（Amadeus Self-Service，国际 GDS 开发者平台）。默认关闭——未配置 Key 时渠道显示"未配置 API Key"，不假装接入。启用三步：

1. 注册：https://developers.amadeus.com （免费），创建应用拿到 API Key（client_id / client_secret）。
2. 配置：复制 `src/sources/amadeus_config.example.json` 为 `src/sources/amadeus_config.json`，填入 Key；若走代理，填 `proxy`（如 `http://127.0.0.1:7897`），并确保代理放行 `*.amadeus.com`。
3. 重启 `python src/webapp.py`，渠道"Amadeus 真实接口"即变为可用，查询结果带"真实接口"标注。

内置调用纪律（自动生效）：Token 缓存复用、同航线同日期结果缓存 30 分钟、**当日最多 200 次调用**（达到自动停用当日渠道）、超时 10 秒、遇 429 立即停不重试。注意：Amadeus 对**中国国内航线覆盖有限**，返回为空时如实显示无报价；测试环境数据可能为缓存，购买以官方渠道为准。

## 接入聚合数据「航班机票查询」（可选，按次计费，默认关闭）

补 **RapidAPI 在国内线的两个缺口**：航线覆盖差（`INC→CTU` 类返回 204）与"有航班无价"
（实测 `INC→SZX 2026-10-27` 的奥凯 BK3037，Google Flights 无价，聚合数据给 ¥918）。

1. 注册 https://www.juhe.cn/ → 申请「航班机票查询」→ 审核通过后在「我的 API」取 **AppKey**。
2. 写入 `src/sources/juhe_config.json`：`{"api_key": "<AppKey>", "endpoint": "", "proxy": ""}`。
3. 重启 `python src/webapp.py`，渠道「聚合数据·航班机票」即 `active`；未配置 Key 时 `not_available`，**不发起任何请求**。

**计费提醒**：免费试用只有 **3 次**（不是"每日 100 次"），正价 ¥99/450 次 ≈ 0.22 元/次。
内置硬停：**当日 20 次 / 当月 60 次**，触顶即降级并给中文原因，**绝不自动充值**；
结果缓存 6 小时、空结果 30 分钟。接口参数与坑见 `docs/09-juhe-integration.md`。

**价格口径**：`ticketPrice` 是否含机建燃油上游未明示，按票面价处理（`tax_included=false`），
到手价由引擎补"机建 ¥50 + 燃油"并逐行标注——不把它当成含税价，避免低估。

## 作为 MCP Server 使用（v1.15.0，AI 客户端可直连）

本产品同时是一个 **MCP Server**（纯标准库实现，stdio 传输，零依赖）：把 `search_flights` / `list_deals` / `list_sources` / `favorites` / `spring_flights` / `spring_coupon_quote` 六个工具注册给 MCP 客户端（ZCode、Claude Desktop 等），AI 可直接调用比价。数据与网页/CLI 完全同源。

**无报价不等于没航班**（v1.14）：上游有时返回真实航班却不给价（例如银川→深圳 2026-10-27 的 BK3037）。此时结果行照常出现，金额位显示「价格未披露」，该行不参与排序与最低价判断——不会因为"没价"而把航班藏起来，也绝不拿 0 或估算值顶上。

其中春秋券库刻意拆成两级：`spring_flights` 只回答"这条航线这一天有没有券可用"，**不返回任何价格**；`spring_coupon_quote` 才按券规则折算单价（209 元秋季 2 次卡 → 104.5 元/次），且含税费与不含机建燃油的券**不合并排名**。详见 `docs/08-spring-coupon-design.md`。
