# 低价票雷达 FareRadar

**这是什么**：一个命令行比价工具——把"航司直连价"和"抖音团购套餐价"放进同一个窗口，从低到高排好，最低价一眼可见；团购票的有效期、退改规则、"要去抖音 App 下单"这些坑全部写在明面上。

**这不是什么**：它不卖票、不收钱、不跳支付，也不能告诉你明天的真实票价——所有价格都是内置模拟数据，工具会在每一屏主动声明。

**怎么用**：只需要 Python，零安装、零配置，三条命令（`search` / `deals` / `watch`）。

## 环境要求

- Windows 10/11 + Git Bash（或任何能跑 Python 的终端）
- Python 3.10+，**只依赖标准库，无需 pip 安装任何东西**

## 3 分钟上手

```bash
# 第 1 步：进入项目目录
cd fare-radar

# 第 2 步：搜索比价（出发三字码 --from、到达三字码 --to、日期 --date）
python src/fareradar.py search --from SHA --to CTU --date 2026-11-15
```

## 命令参考

| 命令 | 作用 | 常用参数 |
|---|---|---|
| `search --from A --to B --date D` | 多票源比价：口径可比（含税）价升序 + `◀ 最低价` 标记；不含税行标注"税费另计"且不参与最低价竞争 | `--source simulated_airline/douyin_groupbuy` 只查一个票源 |
| `deals [--from A] [--to B]` | 团购专区：价格/航线/有效期/库存/退改规则/下单提示 | 过滤参数可省略 |
| `watch --from A --to B --price N` | 设置/更新某航线底价（存于仓库根 `alerts.json`） | |
| `watch` | 立即检查全部关注航线（按明天出发的模拟最低价） | |
| `watch --list` / `watch --from A --to B --remove` | 列出 / 删除关注 | |

日期必须 `YYYY-MM-DD` 且不早于今天；已接入航线：SHA/PEK/CTU/KIX 之间的 5 条模拟航线。参数错误会给出中文说明，退出码非 0。

## 常见问题

**数据是模拟的吗？** 是。每一屏输出首行都有"[模拟数据]"声明；模拟票源只有 5 条航线，查不到的航线会明确说"暂无可用报价"，不会编造。

**团购票怎么买？** 本工具不能购买。卡面上的"下单方式"写明：需在抖音 App 内下单；下单前务必看清退改规则与有效期，显示"未披露"的套餐请先在购买页确认。

**为什么比官网便宜？** 模拟数据还原的是现实中抖音团购的定价逻辑：渠道补贴与库存特卖带来低价，代价是有效期短、限指定航班、退改苛刻甚至不可退。便宜和限制是同一枚硬币的两面，工具把它们一起给你看。

## 已知限制（v1.0）

- 全部数据为内置模拟数据，无真实票价；不接入任何网络。
- 不能购票、支付或跳转下单；团购券的交易与售后都发生在抖音 App 内。
- `watch` 只在"查询时判断"，无后台轮询与系统推送；删除 `alerts.json` 即清空全部关注。关注文件损坏时工具会警告并拒绝操作（不会静默覆盖你的数据），需手工修复或删除后重新设置。
- 暂不支持往返、多航段、舱位/时段筛选与 `--json` 机读输出。
