## 一、范围与策略

1. **功能正确性**：对照 PRD 4.2/4.3/4.4 验收标准逐条设计用例。
2. **边界与异常输入**：非法日期、不存在日期、过去日期、今天日期、相同出发到达、未知三字码、未接入航线、未知票源、watch 参数组合（缺 `--price`、`--price 0/负数/非数字`、`--remove` 缺航线）。
3. **文档一致性**：README 三段示例命令逐条照抄执行，输出与 README 宣称逐字比对；README"命令参考/常见问题/已知限制"中的可测声明逐条核验。
4. **诚实披露**：所有含价格输出首行"[模拟数据]"声明；团购卡五要素（价格/航线/有效期/退改规则/下单方式）与"需在抖音 App 内下单"；缺字段"未披露"兜底。
5. **总协调者指定的确认测试**：① 含税/不含税混排比价（PR-001 评审意见 1）；② alerts.json 损坏静默清空（PR-001 评审意见 3）。实测确认后正式提 Issue。
6. **非功能**：性能（PRD：单次命令 2 秒内）、管道/重定向下中文不乱码、单测回归（Dev 留档 21 例）。

说明：PRD AC"票源失败降级"（4.2 AC2）需注入故障票源，黑盒测试不改 src/，故以 Dev 单测套件（含降级用例）复跑作为间接证据，并在交接文档中注明保留意见。

## 三、用例明细

### TC-01 search 主路径（通过）
- 前置：无 alerts.json。
- 步骤：`python src/fareradar.py search --from SHA --to CTU --date 2026-11-15`
- 预期：合并两票源、价格升序、最低价带 `◀ 最低价`、首行含"模拟数据"、每行含票源/航班或套餐/价格/含税口径、团购行带"团购"标识、退出码 0。
- 实际（摘录，exit=0）：
  ```
  [模拟数据] 以下价格来自内置模拟票源，非真实报价，不能用于实际购票。
  航线：上海(SHA) → 成都(CTU)   日期：2026-11-15（周日）
  ¥459  抖音团购源(模拟)  川航联营 上海-成都 双城券     含税    团购 ▶ 需抖音App下单｜有效期 2026-11-15~2026-12-10
        ◀ 最低价
  ¥499  抖音团购源(模拟)  春秋航空 上海-成都 3日有效券  含税    团购 ▶ 需抖音App下单｜…
  ¥650  模拟航司源        9C8905                        不含税  春秋航空 直飞，无免费餐食
  ¥800  模拟航司源        MU5401                        含税    空客A321 直飞
  ```
- 结论：升序 459<499<650<800，标记唯一且位于最低价行下方，AC1/AC3 全部满足。**通过**。

### TC-02 日期校验（通过）

### TC-18 含税/不含税混排比价（失败 → ISSUE-001）
- 前置：无。
- 步骤：`search --from SHA --to PEK --date 2026-11-03`
- 预期："帮你找最低价"的产品，排序应反映用户真实到手价（或至少明确区分口径排序）。
- 实际（摘录，exit=0）：
  ```
  ¥649  抖音团购源(模拟)  南航联营 上海-北京 7日有效券  含税    …
        ◀ 最低价
  ¥820  模拟航司源        CZ3908                        不含税  波音787 直飞
  ¥890  模拟航司源        MU5101                        含税    空客A330 直飞
  ```
  CZ3908（¥820 **不含税**）排在 MU5101（¥890 **含税**）上方；用户到手价 CZ3908 还需加机建+燃油（国内通常每段约 ¥70~¥170），实际可能比 ¥890 更贵。2026-11-05 同样复现（¥790 不含税排在 ¥860 含税上方）。
- 结论：**失败**。正式提交 ISSUE-001（PR-001 评审意见 1 经实测确认）。

### TC-19 alerts.json 损坏静默清空（失败 → ISSUE-002）
- 步骤：① 正常设置 1 条关注（SHA→PEK ¥700）；② 手工将 `alerts.json` 写坏：`printf '{oops broken' > alerts.json`；③ 裸 `watch`；④ `watch --from SHA --to CTU --price 500`；⑤ 查看文件。
- 预期：检测到文件损坏时给出中文警告，且不得以空清单覆盖原文件。
- 实际：③ 输出"暂无关注航线。"（exit=0，无任何损坏警告）；④ 输出"已保存关注…"（exit=0）；⑤ 文件内容只剩新设的 1 条，原 SHA→PEK ¥700 关注被静默覆盖丢失，全程无警告、无备份。
- 结论：**失败**。正式提交 ISSUE-002（PR-001 评审意见 3 经实测确认）。

### TC-20 团购券有效期不覆盖出发日期仍标最低价（失败 → ISSUE-003）
- 步骤：`search --from SHA --to PEK --date 2026-11-03`；`search --from SHA --to CTU --date 2026-10-24`。
- 预期：参与比价/触发"可以出手了"提醒的团购券，其有效期应覆盖搜索的出发日期（或显著警告不覆盖）。

- 结论：**失败**。正式提交 ISSUE-003。

## 六、总体结论

P0 验收标准（search 合并排序与标记、deals 五要素与兜底、模拟数据声明、参数错误退出码）全部实测通过，产品主路径"3 分钟找到最低价"成立；但 3 个实测确认的问题集中在**比价正确性与用户数据安全**（含税口径混排、alerts.json 静默清空、有效期不匹配仍推荐），恰好都落在"用户信任"这一产品核心承诺上，建议 PM 优先 Triage ISSUE-001/002。
