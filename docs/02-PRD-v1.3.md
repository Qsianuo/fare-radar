## 1. 背景与目标

评审人结论：v1.2.1"能用但不像产品"。本版目标：把网页版从"演示工具"升级为"像个真产品"——中文零门槛、票源有行情感、价格有波动感、收藏有陪伴感——同时演示数据的诚实披露只加强、不放松。

## 2. 非目标（仍然不做）

真实数据与真实渠道接入；购票、支付、跳转下单；部署上线（仍单机 localhost）；用户系统/账号/多用户；"每秒实时行情"（不制造真实行情错觉）；CLI 命令接口与退出码变更。

## 5. 票源家族（5 个，全部走 Source 适配器注册表）

| 行内显示名 | 定价特征（谁通常最低） | 局限条件（必须披露） | 渠道原型 |
|---|---|---|---|
| 航司直连 | 中等；直飞正班，部分报价不含税（行内"税费另计"） | 退改按航司规则 | 航司官网/小程序 |
| OTA 比价 | 常出全场最低或次低；偶有不含税低价引流 | 代理票退改更严、可能收服务费 | OTA 平台 |
| 抖音团购 | 淡季航线常为全场最低（含税） | 有效期=可出行窗口；退改可能未披露；需抖音 App 下单 | 抖音团购套餐 |
| 抖音小程序·春秋航空 | 常有低于航司直连的特价直飞（含税） | 不含行李额、时段偏早晚；退改严；需抖音 App 跳转小程序下单 | 航司自营抖音小程序 |
| 抖音直播间 | 限量闪购可能全场最低，但库存少、易售罄、有效期短（如 3 日） | 限时限量、不可退、需进直播间/App 下单 | 直播间闪购 |

**命名与诚实披露的分工**：行内票源名=用户语言（上表左列），不带"模拟"字样；"这是演示数据"由页面顶部常驻声明（web）与输出首行声明（CLI，措辞统一为"演示数据"）统一承担；风险标记（退改不明/已售罄/税费另计/有效期不覆盖）仍逐行保留。5 源全部自动进入 CLI 比价（同一注册表）。

## 6. 任意航线定价

- 注册表内任意起讫组合（起≠讫）必须能出模拟报价：按大圆距离生成基础价，叠加确定性因子（航线、票源家族特征、星期、舱位）。
- 兜底话术保留：极端情况（同城市、无效码）仍输出"该航线暂无可用报价"类中文提示，不崩溃、不编造。
- 判定：任取两城（如 沈阳→三亚、昆明→香港）均出合理报价，且"远贵近廉"的大趋势可见。

## 7. 演示波动

- 定义：价格随时间**确定性**小幅起伏（幅度与周期由技术方案定），因子=f(航线, 票源, 时间段)；**同一分钟内任何入口（CLI/网页）查同航线同票源价格一致**（规则唯一来源的可感证据）；分钟之间可见变化。
- 标注：仪表与结果页显著标注"演示波动"；禁止出现"实时""秒级""行情"等暗示真实市场的词。

## 8. 收藏航线与首页价格仪表

- **收藏航线**（替代"低价提醒"表述及解释性文案）：收藏=保存航线，可附带底价（不强制）；收藏页一眼看到每条航线当前最低价，低于底价的行用**绿色标记**（绿色全场唯一语义）；数据与 CLI watch 同源 alerts.json——CLI 设的底价网页可见、网页收藏 CLI 可见；数据结构仅一处授权演进：底价允许为空（存量数据完全兼容）；CLI 命令名与参数不变。
- **首页价格仪表**：默认展示选中航线（默认上海→成都）的当前最低价大字号呈现 + 价格区间可视化（SVG 弧形表盘或区间条，标注当前价在今日区间中的位置）+ 近 24 小时演示价格曲线（确定性重放生成）+ 常驻"演示数据/演示波动"标注。

## 9. UI 升级设计原则（不做像素稿，验收=原则符合性）

1. **信息层级**：一屏一主任务；价格是第一视觉（大字号、高对比）。
2. **信任感**：演示数据声明常驻首屏但不喧宾夺主；风险标记统一视觉语言。
3. **一致性**：票源名、口径、提示语与 CLI 同词表（同一数据源渲染）。
4. **可及性**：纯 CSS 实现视觉升级，无外部字体/框架/CDN；中文排版对比度达标；窄屏可读。
5. **克制**：无动效堆砌；绿色仅用于"低于底价"一个语义。

## 10. 验收标准（黑盒可测）

- AC1 城市下拉：出发/到达为完整中文下拉，25 城全部可选、无需输入过滤；选中后显示中文城市名。
- AC2 任意航线：任选注册表两城（含国际，如 昆明→曼谷）均出报价；同城市/无效输入出中文兜底提示。
- AC3 五票源：同一航线结果包含全部已接入票源，行内名如第 5 节、无"模拟"字样；页顶常驻演示声明；CLI 行内名同步一致。
- AC4 演示波动：同一分钟内 CLI 与网页同航线最低价一致；隔分钟可见变化；"演示波动"标注可见。
- AC5 收藏：网页收藏航线（设/不设底价两种）后 CLI `watch --list` 可见；CLI 设底价后收藏页出现绿色"低于底价"标记；删除双向同步。
- AC6 仪表：首页有大字号最低价+区间可视化+24 小时曲线，且明确标注演示数据。
- AC7 UI 原则：第 9 节 5 条逐条检查通过。
- AC8 回归：P0 口径不回退（到手价准入、有效期/售罄/退改不明标记、alerts 损坏保护、参数错误退出码）。

## 11. 用户视角（铁律自查）

1. **用户能看到什么**：满屏中文城市、5 个叫得出门的票源名、"会呼吸"的价格（演示波动如实标注）、一个大得不用找的最低价仪表；每一屏都知道"这是演示数据"。
2. **用户能做到什么**：不懂三字码也能查任意两城比价；常查航线收藏后一打开就看到"今天最低多少、到我底价没有"。
3. **用户会感受到什么**：像个真产品，但它不装——演示数据、演示波动都写在明面上；便宜的兴奋感与"这是练习场"的清醒感并存。
