## 1. 产品定位

一句话：**帮预算敏感的旅客，在一个命令行窗口里，把航司直连价与抖音团购套餐价放在一起比，并诚实标出每种票的限制。**

用户眼中的产品：一个"不绕弯子的比价小工具"。它不是购票渠道——不收钱、不出票、不跳支付；它替用户把分散的票源扫一遍，挑出最低价，把团购票的有效期、退改规则、"要去抖音 App 下单"这些坑写在明面上。所有价格为模拟数据，工具必须主动说清楚。

## 2. 目标与非目标

### 2.1 V1.0 目标
- **G1 比价**：一条命令得到多票源合并的价格排序，最低价一眼可见。
- **G2 透明**：团购套餐单独成区，价格/航线/有效期/退改规则/下单方式五要素齐全。
- **G3 提醒**：可设心理底价，查询命中时得到醒目提示。
- **G4 开箱即用**：全中文输出，仅依赖 Python 3.10 标准库，Windows Git Bash 直接运行。

### 2.2 非目标（V1.0 明确不做，附理由）
| 不做 | 理由 |
|---|---|
| 出票、支付、代下单（含代购团购券） | 无资质且涉资金风险；工具定位是"雷达"不是"柜台" |
| 接入真实网络数据源 | 总协调者已拍板模拟数据；真实接入路径见 04 文档里程碑 |
| GUI / 网页 / 移动端 | 核心价值在信息合并与披露，CLI 已足够；防范围膨胀 |
| 往返、多航段、舱位/时段筛选 | 主路径是"单程直飞比价"，先跑通再谈丰富 |
| 价格预测、历史趋势图 | 依赖真实数据积累，模拟数据下无意义（列 v1.1 后备） |

## 3. 用户画像（摘要）

小林，24 岁，二线城市初级职员/研究生，月可支配约 4000 元，每年 2-4 次出行；购票前习惯多 App 比价，刷到过抖音机票团购但不敢直接买。核心诉求：便宜、透明、不踩坑。详见 02-requirements-research.md。

## 4. V1.0 功能范围

### 4.1 范围裁量说明（PM 最终决定及理由）
- 收敛为 3 个命令：`search`（搜索比价）、`deals`（团购专区）、`watch`（低价提醒）。与总协调者拍板一致，PM 复核后**维持不加不减**，理由：
  - `deals` 独立于 `search`：团购卡的信息维度（有效期/退改/库存/下单路径）远多于一条价格行，塞进搜索结果会挤压关键披露信息；独立专区也强化"团购票要单独看清规则"的产品心智。
  - `watch` 保留但降为 P1：价值真实（等待降价是高频诉求），但 V1.0 只做"查询时判断"的轻实现，不阻塞主路径。
  - 不加 `config` 命令：提醒的增删查用 `watch` 子命令即可覆盖，避免命令面膨胀。
- 优先级定义：P0 = V1.0 缺一不可，验收不过不发布；P1 = V1.0 包含，允许最简实现；P2 = backlog，不承诺。

### 4.2 功能一：搜索比价（P0）
命令：`search`，参数含出发地、目的地、日期（CLI 具体形态由技术方案定，参数语义不变）。

**用户故事**：作为预算敏感的旅客，我想用一条命令按出发地/目的地/日期搜出所有已接入票源的票价并从低到高排好，以便不开 N 个 App 就知道哪张票最便宜。

**验收标准（Given/When/Then）**
- AC1 Given 仅安装 Python 3.10 标准库，When 执行合法 search，Then 输出合并全部可用票源的结果列表，按价格升序，最低价行带文字标记 `◀ 最低价`，且输出首行含"模拟数据"声明。
- AC2 Given 任一票源适配器失败，When 执行 search，Then 其余票源正常展示，失败票源处显示中文提示（如"XX 源暂不可用"），整体查询不中断。
- AC3 Given 结果中任意一行，Then 至少含：票源名、航班号/套餐名、价格与币种、是否含税口径；团购来源行带"团购"标识。
- AC4 Given 参数缺失或日期格式非法，When 执行，Then 输出中文错误说明与用法示例，进程退出码非 0。
- AC5 Given 已设低价提醒且当前最低价 ≤ 底价，When 执行 search，Then 输出顶部出现 `[低价提醒]` 行。

### 4.3 功能二：团购专区（P0）
命令：`deals`，可按出发地/目的地过滤。

**用户故事**：作为想省钱但怕踩坑的旅客，我想单独浏览抖音团购套餐卡，以便下单前就知道有效期、退改规则，以及"必须去抖音 App 下单"这件事。

**验收标准**
- AC1 Given 执行 deals（无过滤），Then 每张套餐卡完整展示：套餐名、航线、价格、有效期起止、库存状态、退改规则全文、购买入口提示（显著标注"需在抖音 App 内下单"）、"模拟数据"声明。
- AC2 Given 过滤后无匹配，Then 输出"当前航线暂无团购套餐"的中文提示，不报错、不输出空卡。
- AC3 Given 某字段在数据源缺失（如退改规则），Then 显示"未披露，下单前请在购买页确认"，禁止留空或省略（诚实披露红线）。

### 4.4 功能三：低价提醒（P1）
命令：`watch`，支持设置/列表/删除。**V1.0 范围为"查询时判断"**：不做后台轮询、不做系统推送——单机 CLI 无常驻进程，轮询超出"小而完整"的边界（理由见 4.1）。

**用户故事**：作为盯着某条航线等降价的旅客，我想把心理底价记在工具里，以便每次查询时一旦价格降到阈值以下，立刻得到提醒。

**验收标准**
- AC1 Given 执行设置（如 `watch --from 上海 --to 成都 --price 700`），Then 阈值被本地持久化并输出中文确认信息。
- AC2 Given 已设阈值，When 低价命中（见 4.2 AC5），Then 提醒行包含当前最低价、底价与命中结论；未命中时不出现提醒（可有一行未达提示）。
- AC3 Given 执行列表与删除，Then 能查看全部阈值并删除指定条目，删除后不再触发提醒。

### 4.5 优先级总表
| 功能/要求 | 优先级 | V1.0 实现 |
|---|---|---|
| search 合并排序 + `◀ 最低价` 标注 | P0 | 完整 |
| deals 团购卡五要素 + 抖音下单提示 + "未披露"兜底 | P0 | 完整 |
| 模拟数据诚实声明（所有含价格的输出） | P0 | 完整 |
| 可插拔票源适配器接口（字段契约见 04 文档） | P0 | 完整：新增模拟源只加适配器，不改 search/deals 逻辑 |
| 票源失败降级提示 | P1 | 最简 |
| watch 低价提醒（查询时判断） | P1 | 最简 |
| `--json` 机读输出 | P2 | backlog |
| 历史价格记录、筛选器、颜色高亮 | P2 | backlog |

## 5. 非功能性要求

- **语言**：面向用户的输出全部为简体中文；文档编码 UTF-8。
- **环境**：Windows 10 + Git Bash + Python 3.10；仅标准库、零第三方依赖；不得因 ANSI 颜色缺失丢信息（关键标记用文字符号）。
- **诚实披露（红线）**：所有含价格的输出首行标注"模拟数据，非真实报价"；团购输出必含"需在抖音 App 内下单"与退改规则；数据缺失显示"未披露"。
- **健壮性**：单票源失败不拖垮整体；参数错误退出码非 0；全程不发起真实网络请求。
- **性能**：模拟数据下单次命令 2 秒内返回。
- **可测试**：核心逻辑（排序、阈值判断、字段兜底）可被自动化测试覆盖。

## 6. 成功指标

- **S1（北极星）**：User A 仅凭 README，3 分钟内完成一次 search 并正确回答"最低价多少、来自哪个票源"。
- **S2 透明度**：User A 能复述任一团购套餐的退改限制与下单方式，反馈"信息够、没意外"。
- **S3 信任度**：User A 明确知道数据为模拟、工具不能出票，未产生"这是真实报价"的误解。
- **S4 工程**：Tester 黑盒用例 P0 全通过；零依赖机器直接运行成功。

## 7. 用户眼中的产品

**第一次打开**：README 顶部三句话——"这是什么（比价雷达）/ 不是什么（不能买票、非真实报价）/ 三条命令怎么用"。不读源码、10 分钟内能跑通示例。

**完成核心任务的操作与预期输出样式**（示意，最终以技术方案与 README 为准）：

```
$ python -m fareradar search --from 上海 --to 成都 --date 2026-11-15
[模拟数据] 以下价格来自内置模拟票源，非真实报价，不能用于实际购票。
[低价提醒] 当前最低 ¥649 ≤ 你的底价 ¥700，可以出手了！
----------------------------------------------------------------------
价格    票源          航班/套餐               含税    备注
¥649   抖音团购源(模拟) 春秋 上海-成都 3日券      含税    团购 ▶ 需抖音App下单
        ◀ 最低价
¥780   南航模拟源      CZ3488 直飞             不含税   退改见航司规则

$ python -m fareradar deals
[模拟数据] 以下团购套餐来自模拟数据源，非真实商品。
┌ 套餐：春秋航空 上海-成都 3日有效券
│ 价格：¥649（含税） | 库存：紧张
│ 有效期：2026-11-01 ~ 2026-11-30
│ 退改规则：未使用可退，收 30% 手续费；过期作废
│ 下单方式：需在抖音 App 内下单，本工具不提供购买
```

**用户感受检验**：省心（一次看全）、可信（坑都写了）、克制（不夸大、不打扰）。

## 8. 用户视角（铁律自查）

1. **用户能看到什么**：全中文输出；最低价有 `◀ 最低价` 标记；团购卡披露退改规则与下单方式；每一屏都标注"模拟数据"。
2. **用户能做到什么**：不读代码、只看 README，3 分钟内完成"找到最低价"这一核心任务。
3. **用户会感受到什么**：便宜看得见、坑写得明、"模拟"不冒充真——省心且不被套路。
