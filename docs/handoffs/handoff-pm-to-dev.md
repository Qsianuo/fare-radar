## 二、关键产品决策（Dev 必须遵守）

1. **3 个命令**：`search`（搜索比价）、`deals`（团购专区）、`watch`（低价提醒）；`watch` 允许最简实现——"查询时判断"，不做后台轮询与系统推送。
2. **诚实披露红线**：所有含价格的输出首行标注"模拟数据，非真实报价"；团购卡必含退改规则全文与"需在抖音 App 内下单"提示；数据字段缺失时输出"未披露"，禁止留空。
3. **全中文输出**；最低价用文字标记 `◀ 最低价`，关键信息不得依赖 ANSI 颜色。
4. **可插拔适配器**：新增模拟票源只加适配器文件并注册，不改 `search`/`deals` 逻辑；字段契约见 04 文档第三节（`deal_id`、`route`、`price`+含税口径、`valid_from/until`、`stock`、`purchase_entry`、`refund_change_rules` 等）。
5. **每行价格必标含税口径**；团购来源行必带"团购"标识。
6. 不发起任何真实网络请求；不做购票/支付入口。

## 三、请研发确认的问题（3 个，附 PM 倾向答案）

- **Q1 入口形态**：`python -m fareradar` 还是 `python src/fareradar.py`？**倾向**：以 `src/fareradar.py` 单文件入口为主（零配置最友好），符合宪法目录约定；若模块化后需要 `-m`，两者都支持亦可，以 README 写清楚为准。
- **Q2 提醒数据存储**：存哪、什么格式？**倾向**：项目根目录 `fare-radar-watch.json`，标准库 `json` 读写，结构约 `{route, threshold, created_at}`；单文件即可，不搞数据库。
- **Q3 搜索参数语法**：`--from/--to/--date`（英文 flag + 中文城市值）还是中文位置参数？**倾向**：`--from/--to/--date` 英文 flag + 中文值，`--help` 全中文——flag 对解析更稳妥，中文值保持用户友好。

## 四、验收标准摘要（全量见 PRD 第 4 节，验收以 PRD 为准）

- **search（P0）**：多源合并、价格升序、`◀ 最低价` 标记、首行模拟数据声明、每行含税口径与团购标识；参数错误中文提示 + 退出码非 0。
- **deals（P0）**：每卡五要素（价格/航线/有效期/退改规则/下单提示）+ 库存 + 模拟声明；空结果友好提示；字段缺失显示"未披露"。
- **watch（P1）**：设置/列表/删除；命中时输出含当前最低价、底价、结论的 `[低价提醒]` 行；删除后不再触发。
- **降级（P1）**：单票源失败显示"XX 源暂不可用"，不影响其余结果。
- **工程（P0）**：仅 Python 标准库；单次命令 ≤2 秒；可插拔性（新增源不改既有逻辑）。

## 五、研发完成后的验收流程（谁、看什么）

1. **Dev 自测**：`tests/` 全绿 + README 按"用户视角"写好 → PR-001 落盘 `prs/`（描述、变更清单、自测证据）。
2. **总协调者 Code Review**：对照 PRD AC 逐条核对（重点：诚实披露红线、可插拔性、退出码），结论写回 PR-001。
3. **Tester 黑盒（S3）**：按 PRD 验收标准设计用例 → `docs/05-测试计划与结果.md`；问题提 `issues/ISSUE-00X.md`。
4. **User A 旅程验收（S3）**：只看 README，验证"3 分钟找到最低价"（成功指标 S1-S3）→ `docs/06-用户旅程.md`。**User A 说 OK 才算 OK。**
5. **不通过项**回流 S4：PM Triage 定级 → S5 修复 → 回归 → 发布 v1.1.0（或 v1.0.1）。

## 六、给 Dev 的坑提示

1. Windows 控制台 GBK 与 UTF-8 编码问题：中文输出需在技术方案中显式处理，评审会重点看乱码。
2. `--from` 作为 argparse 参数名合法，但注意与 Python 关键字区分（`from_` 命名内部变量）。
3. 测试必须覆盖"票源失败降级"与"字段缺失兜底（未披露）"两条路径，这是披露红线的技术保障。

## 用户视角

- Dev 交付的不只是能跑的代码，而是"用户第一次打开，只看 README 就能 3 分钟找到最低价"的体验；README 与输出文案同代码同等重要，缺一样都不算完成。
- 判断标准始终是三个问题：用户能看到什么（披露是否清楚）、能做到什么（3 分钟门槛）、会感受到什么（可信、省心、不套路）。
